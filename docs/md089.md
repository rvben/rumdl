# MD089 - Single blank line before heading

Aliases: `single-blank-line-before-heading`

**Disabled by default.** This rule is opt-in: enable it explicitly with
`extend-enable`.

This rule checks that every heading is preceded by exactly one blank line, improving readability and visual consistency.

## Why This Matters

- **Readability**: Exactly one blank line creates consistent visual separation between sections
- **Parsing**: Some Markdown parsers require blank lines before headings for proper rendering
- **Consistency**: Enforces a uniform document style throughout
- **Focus**: Helps readers identify and focus on section transitions

## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `heading-styles` | array of `"atx"` / `"setext"` | `["atx", "setext"]` | Heading styles to check |
| `first-heading-exempt` | boolean | `true` | Whether the first heading in the document is exempt |

## Configuration

### Enable the rule

```toml
[global]
extend-enable = ["MD089"]
```

### Customize

```toml
[MD089]
heading-styles = ["atx"]
first-heading-exempt = false
```

## Examples

### Correct (with default configuration)

```markdown
# Title

## Section 1

Content in section 1.

## Section 2

More content.
```

### Incorrect (with default configuration)

```markdown
# Title
## Section 1

Content in section 1.


## Section 2

More content.
```

The first issue (`## Section 1`): no blank line before the heading.
The second issue (`## Section 2`): two blank lines before the heading.

## Fix

The rule can automatically fix all violations:

- Insert a blank line before headings that have no preceding blank line
- Remove excess blank lines (2+) before headings, leaving exactly one
